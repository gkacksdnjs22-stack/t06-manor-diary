# 대저택 제작 일지 · T06

계획 → 할 일 → 실제 작업 → 돌아보기 → 다음 계획을 연결하는 한국어 앱입니다.

## 실행

Node.js 22.13 이상. `npm ci`, `npm run db:generate`, `npm run build` 순으로 실행합니다. 생성된 `dist/server/wrangler.json`으로 `drizzle/*.sql`을 번호 순으로 로컬 D1에 적용한 뒤 `npm run dev -- --port 5178`을 실행합니다. 자세한 로컬 명령은 `STARTER_RUNTIME.md`에 있습니다.

## 실제 기록과 남은 입력

- 학생이 정한 목표: 대저택 지하·1·2·3층을 생각한 구조와 디자인으로 완성.
- 기한: 2026-10-11. 구조 설계 시작일: 2026-09-29.
- 예상 시간: 학생 요청에 따라 미정. 숫자 0시간으로 판단하지 않으며 화면에는 미정으로 표시합니다.
- 학생이 알려 준 작업: 전체적인 저택의 구조 설계, 진행 중.
- 학생이 알려 준 막힌 이유: 디자인이나 전체 구조 설계가 이상해집니다.
- 이 정보만으로 완료된 실행 기록의 시작·종료 시각 또는 실제 소요 시간을 만들지 않았습니다.
- 층별 완성과 동선 검수 할 일은 기존 작업과 사용자 목표를 바탕으로 정리한 초안입니다. 사용자가 검토하고 고칠 수 있습니다.
- T06 제출 전에는 예상 시간 확정과 실제 실행 기록 3개 이상 입력이 필요합니다. ‘미정’은 임시 입력 상태이며 시간 저장 요건의 완전한 충족으로 보고하지 않습니다.
- ALEPH 과제 제출은 아직 하지 않았습니다.

## 기능

실제 D1 서버 데이터베이스, 계획별 불변 수정 이력, 할 일 생성·수정·완료·되돌리기·삭제, 검색·상태와 태그 필터·명시된 정렬, 별도 실행 기록, DB 제약과 원자적 batch로 완료 중복 방지, 서울 날짜 기준 집계, 숫자에서 근거 기록으로 이동, 돌아보기 개선점을 다음 계획으로 전달, 전체 JSON 내보내기.

자료는 공개 읽기·쓰기로 동작합니다. 첫 화면에 로그인 없는 공개 상태를 알립니다. 비밀키나 개인정보를 넣지 않습니다. 로그인은 후속 과제 범위입니다.

## 검증

`node tests/api.mjs`는 로컬 서버의 별도 합성 계획을 만들어 9개 통합 검사를 수행합니다. `node tests/domain.mjs`는 집계와 서울 날짜 경계를 검증합니다. 합성 자료를 학생의 실제 기록으로 사용하지 않습니다. `tests/api-results.json`은 합성 실행 증거입니다. 최종 스키마 및 날짜·집계 규칙: `contracts/pds-schema-v2.json`.
